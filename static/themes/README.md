# Дизайны эфирной графики

Каждая подпапка — отдельный дизайн: `css/`, `js/`, `fonts/`, `images/` (всё необязательно).
Выбор дизайна: панель → «Настройки» → «Дизайн эфирной графики» (применяется по кнопке «Сохранить настройки»).

- **1. LIGA** — `static/themes/liga` (светлый дизайн).
- **2. FPR** — `static/themes/fpr` (синий дизайн).
- **3. Старый** — исходный вид проекта (обычные файлы `static/css`, `static/js`, `static/images`), папки не требует.

Файл темы с тем же именем, что у стандартного, заменяет его
(`static/themes/fpr/css/vs.css` вместо `static/css/vs.css`). Чего в теме нет, берётся стандартное.
Фоны (`bg_*.png`, `display_bg.png`, `pool_bg.png`) лежат как в оригинале; свой фон можно положить
в `static/themes/<имя>/images/` под тем же именем (для `display_bg.png` и `pool_bg.png`).

Новый дизайн: создайте папку `static/themes/<имя>/`, при желании добавьте `theme.json` вида `{"title": "Название", "order": 3}`.
Выбранный дизайн хранится в `data/active_design.txt`.

Шрифт TT Bluescreens в темах — пробная (Trial) версия; для коммерческого эфира нужна полная лицензия.
